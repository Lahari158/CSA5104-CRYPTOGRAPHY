## Capstone Implementation – Overview

The capstone project is a **Post-Quantum Cryptography (PQC) File Transfer System** implemented as a Python-based Streamlit web application.

The system demonstrates secure file handling using cryptographic techniques for confidentiality, integrity, authentication, access control, and security monitoring.

### Major Components

- **Authentication** – User registration and secure login
- **PQC Key Management** – Post-quantum cryptographic key generation and management
- **File Encryption** – Secure file encryption and decryption
- **Integrity Verification** – SHA-256 based file integrity checking
- **Digital Signatures** – Digital authentication and signature verification
- **Access Control** – Role-Based Access Control (RBAC)
- **Audit Logging** – Security event monitoring and logging
- **Security Reports** – Audit analysis and report generation
